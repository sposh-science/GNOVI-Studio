# GNOVI Studio Visual Identity

Official visual identity resources for **GNOVI Studio**, an open-source scientific plotting and data-analysis application.

## The Mark

The GNOVI Studio mark combines an open geometric **G** with elements representing scientific plotting, data analysis, and instrumentation.

The open form reflects the project's commitment to open-source scientific software and accessible research tools.

Within the mark, the rising line and circular data points represent scientific plotting and data analysis. The three vertical bars suggest measurement, comparison, and visualization.

The terminal nodes and circuit-like geometry reflect the connection between computation, scientific instrumentation, and experimental research.

Together, these elements represent GNOVI Studio's goal of providing open tools for scientific visualization and analysis.

## Colours

| Colour | Hex | Role |
|---|---|---|
| GNOVI Navy | `#10235F` | Primary mark, GNOVI wordmark, and first data bar |
| Graph Blue | `#347FBE` | Plot line, data points, and STUDIO accent lines |
| Bar Slate | `#66758A` | Middle data bar |
| Light Slate | `#98A6B6` | Right data bar |
| Studio Grey | `#6F7480` | STUDIO wordmark |

The GNOVI Studio visual identity uses flat colours without gradients.

## Typography

The GNOVI Studio visual identity uses **Rajdhani**, an openly licensed typeface.

- **GNOVI:** Rajdhani Bold
- **STUDIO:** Rajdhani Medium

Public distribution SVGs use text converted to vector paths so that the artwork renders consistently without requiring Rajdhani to be installed.

Editable source artwork may retain live text for future modification.

## Identity Assets

- `gnovi-studio-logo.svg` — primary horizontal logo in vector format
- `gnovi-studio-icon.svg` — standalone GNOVI Studio mark
- `gnovi-studio-logo-1000x400.png` — transparent raster version of the horizontal logo
- `gnovi-studio-icon-500.png` — transparent raster version of the icon
- `source/` — editable source artwork

SVG should be preferred wherever scalable vector artwork is supported.

## Visual Usage

For consistent presentation of GNOVI Studio, it is recommended that the proportions, geometry, colours, and relative arrangement of the official artwork be preserved.

When practical, avoid stretching or distorting the artwork, independently recolouring individual elements, rearranging components, or adding effects that reduce clarity.

Adequate clear space around the artwork is recommended so that the open geometry and internal data elements remain visually distinct.

These are **visual identity recommendations only** and do not impose additional restrictions on the freedoms granted under the project's licence.

## Source Files

Editable source artwork is retained in the `source/` directory for maintenance and future development of the GNOVI Studio visual identity.

The public SVG and PNG files are provided for convenient use in project documentation, software interfaces, websites, presentations, and other project materials.
